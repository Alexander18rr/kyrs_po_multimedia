# Курсовая работа по мультимедиа

Этот репозиторий содержит материалы и исходный код курсовой работы по дисциплине "Мультимедиа". Проект включает в себя разработку интерактивного приложения, демонстрацию работы с аудио, видео и графикой, а также примеры использования современных инструментов и библиотек для создания мультимедийных решений.

## Содержание проекта

- Исходный код приложения
- Описание архитектуры и используемых технологий
- Инструкции по запуску и использованию


## Технологии

- Python (библиотеки для обработки мультимедиа)
- HTML/CSS/JavaScript (фронтенд)
- Flask (веб-сервер)

## Файлы проекта

- Файлы HTML, CSS, JS находятся в ветке [feature/html-pages](https://github.com/Alexander18rr/kyrs_po_multimedia/tree/feature/html-pages).

## Установка и запуск

1. Клонируйте репозиторий: git clone https://github.com/Alexander18rr/kyrs_po_multimedia.git
2. Запустите сервер: pysk.py
3. Откройте в браузере: http://localhost:5000 для просмотра приложения.
